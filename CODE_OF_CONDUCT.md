# LifyX Code of Conduct

## Our Commitment

We are committed to providing a professional, respectful and inclusive environment for everyone participating in the LifyX open-source and developer community.

We expect all contributors, maintainers and community members to communicate constructively and respectfully.

## Expected Behavior

Examples of positive behavior include:

- Communicating respectfully
- Providing constructive feedback
- Respecting different viewpoints and experiences
- Focusing discussions on technical and project-related topics
- Accepting feedback professionally
- Helping maintain a productive environment

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment or intimidation
- Personal attacks
- Discriminatory or abusive language
- Threats
- Spam
- Deliberate disruption of discussions
- Publishing private information without permission
- Malicious or destructive activity
- Social engineering attempts

## Scope

This Code of Conduct applies to:

- LifyX GitHub repositories
- Issues
- Pull requests
- Discussions
- Developer collaboration
- Community-managed technical spaces

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please contact:

support@lifyx.exchange

For security-related matters, use:

security@lifyx.exchange

Reports will be reviewed as appropriate and handled with reasonable confidentiality.

## Enforcement

LifyX maintainers may take appropriate action in response to unacceptable behavior, including:

- Removing comments or content
- Closing discussions
- Rejecting contributions
- Restricting participation
- Blocking users from project spaces
