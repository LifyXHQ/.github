# LifyX

**Where AI Powers Your Trading.**

LifyX is a decentralized trading platform and Web3 ecosystem built for the next generation of digital markets.

Our mission is to deliver fast, scalable, self-custodial and privacy-focused trading experiences across Spot and Perpetual markets.

## Ecosystem

- Spot & Perpetual trading
- Self-custodial wallet experience
- Multi-chain connectivity

- Web3 infrastructure
- AI-powered trading ecosystem

## Trading Infrastructure

### LifyX Spot

LifyX Spot provides high-performance decentralized spot trading designed for speed, scale and privacy.

Infrastructure Provider:

`KalqiX`

Core capabilities include:

- Sub-10ms matching
- 250K+ transactions per second
- ZK-proven trades
- Private execution
- Professional order book trading
- High-performance market data
- API-ready trading infrastructure

### LifyX Perpetuals

LifyX Perpetuals provides decentralized perpetual trading across crypto and global markets through a self-custodial trading experience.

Infrastructure Provider:

`Orderly`

Perpetual infrastructure supports:

- Perpetual market data
- Order book trading
- Funding rates
- Funding history
- Mark and index prices
- Recent trades
- Kline data
- Market statistics
- Liquidity access
- Developer integrations

## Security

LifyX follows self-custodial Web3 principles.

Never expose:

- Private keys
- Seed phrases
- Wallet passwords
- API secrets
- Environment secrets

Wallet approvals and transaction authorization remain under the control of the user's wallet provider.
