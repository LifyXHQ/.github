# Contributing to LifyX

Thank you for your interest in contributing to the LifyX ecosystem.

We welcome useful contributions to documentation, developer tooling, examples and public Web3 resources.

## Before Contributing

Before opening a pull request:

- Review the repository documentation
- Check existing issues and pull requests
- Avoid duplicating existing work
- Keep changes focused and clearly scoped
- Do not include sensitive credentials or private information

## Contribution Areas

Contributions may include:

- Documentation improvements
- API example improvements
- Web3 utility improvements
- Bug fixes
- Developer experience improvements
- Test coverage
- Code cleanup
- Integration examples

## Pull Requests

When submitting a pull request:

- Use a clear title
- Explain what was changed
- Explain why the change is useful
- Keep unrelated changes separate
- Include testing notes when applicable
- Update documentation when behavior changes

## Code Quality

Contributions should aim to be:

- Clear
- Minimal
- Maintainable
- Secure
- Well documented
- Consistent with the existing project structure

## Security

Do not report security vulnerabilities through public issues or pull requests.

Please follow the LifyX Security Policy and report vulnerabilities privately to:

security@lifyx.exchange

If unavailable:

support@lifyx.exchange

## Sensitive Information

Never commit:

- Private keys
- Seed phrases
- API secrets
- Access tokens
- Wallet passwords
- Environment secrets
- Production credentials

## Conduct

Contributors are expected to communicate respectfully and professionally.

Harassment, abusive behavior, spam and malicious activity are not tolerated.
